# Third-party material

| What | Where | Licence |
|---|---|---|
| Chess pieces ("cburnett" set) | `assets/pieces/*.svg`, from the Lichess repository | GPLv2+ (Colin M. L. Burnett) |
| IBM Plex Sans / Plex Mono | `assets/fonts/` | SIL Open Font License 1.1 (`assets/fonts/OFL.txt`) |
| Lucide icons (as path data) | `qml/icons.js`, generated by `tools/svg2js.py` | ISC (`assets/LICENSE-lucide.txt`) |
| Qt 6 | linked dynamically | LGPLv3 |
| Stockfish | run as a separate process, not bundled | GPLv3 |

**What this means for you.** The piece set is GPLv2+, so a binary that embeds it should be
distributed under a GPL-compatible licence. Releasing zugfish as GPL-3.0-or-later is the
simplest way to satisfy that (and it fits Stockfish too). If you would rather use a more
permissive licence, swap `assets/pieces/` for a set with a licence you like (Lichess ships
several, e.g. "chessnut" under Apache-2.0) and keep the same file names (`wK.svg` ... `bP.svg`).
